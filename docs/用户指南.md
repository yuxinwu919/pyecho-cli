## 安装

### 前置要求

- Python ≥ 3.10
- ECHO2D 求解器（项目已内置 `ECHO2D_v3_5/` 目录，无需额外安装）
- macOS/Linux 用户：OpenMP 运行时（通常系统自带）

### 安装步骤

```bash
# 克隆仓库
git clone https://github.com/yuxinwu919/pyecho-cli.git
cd pyecho-cli

# 创建虚拟环境（推荐）
python3 -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate

# 安装
pip install -e ".[dev]"

# 验证
echo2d system check
```

## 核心概念

### 项目结构

```
myproject/                  ← 项目根目录
├── .echo2d.yaml           ← 项目清单
├── runs/                   ← 运行目录
│   └── 001_baseline/       ← 第一次运行
│       ├── .run.yaml       ← 运行元数据
│       ├── input_in.txt    ← ECHO2D 参数文件
│       ├── collimator.txt  ← 几何文件
│       ├── round/          ← 输出（圆形几何）
│       │   ├── wakeL_00.txt   ← m=0 模态 wake
│       │   ├── wakeL_01.txt   ← m=1 模态 wake
│       │   └── Iz0.txt        ← 束流剖面
│       └── processed/      ← 后处理输出
│           └── wake/
│               ├── wake_monopole.txt
│               └── wake_dipole.txt
└── ECHO2D_v3_5/            ← 求解器（仓库级）
```

### 几何类型

| 类型 | 说明 | 输出目录 |
|------|------|---------|
| **Round** | 旋转对称结构（圆形管道、腔） | `round/` |
| **Recta** | 矩形截面结构（宽度恒定，高度可变） | `magn/` + `elec/` |

### Recta 几何的特殊性

矩形结构需要运行**两次**：一次 magnetic BC (`magn/`)，一次 electric BC (`elec/`)。CLI 自动处理这两个运行，后处理时合并 `W_cc` 和 `W_ss` 模态系数得到完整 wake。

## 完整工作流教程

### Step 1: 创建项目

```bash
# 列出可用模板
echo2d project templates

# 从模板创建
echo2d project init my_collimator -t round_collimator
cd my_collimator

# 或创建空项目
echo2d project init my_project -t empty
```

### Step 2: 配置参数

```bash
# 查看生成的参数
echo2d config show runs/001_baseline/input_in.txt

# 直接编辑
vim runs/001_baseline/input_in.txt
```

关键参数说明：

| 参数 | 含义 | 典型值 |
|------|------|--------|
| `BunchSigma` | 束团 RMS 长度 [m] | 0.001 |
| `Modes` | Fourier 模态数 | `0 1`（圆形）/ `1 3 5 ...`（矩形） |
| `MeshLength` | 移动网格长度（网格点数） | 52 |
| `StepY` | 横向网格步长 [m] | 0.0002 |
| `StepZ` | 纵向网格步长 [m] | 0.0002 |
| `Offset` | 束团横向偏移（网格点数），-1 为最大 | -1 |
| `SymmetryCondition` | 矩形几何边界条件 | `magn` 或 `elec` |

### Step 3: 创建几何

```bash
# 创建圆形管道-台阶-管道结构
echo2d geometry create mypipe --structure pipe-step-pipe \
    --radius1 0.01 --radius2 0.02 --length1 0.1 --length2 0.05

# 创建矩形 DLW（介质加载波导）
echo2d geometry create mydlw --structure dlw \
    --half-gap 0.005 --width 0.07
```

### Step 4: 运行仿真

```bash
# 在项目目录中
echo2d run start --threads 4

# 或指定运行目录
echo2d run start 001_baseline -j 4

# 带超时
echo2d run start --timeout 3600

# 指定 ECHO2D 可执行文件
echo2d run start --exe /path/to/ECHO2D
```

### Step 5: 后处理

```bash
# 处理 wake（自动检测几何类型）
echo2d postprocess wake runs/001_baseline

# 带绘图
echo2d postprocess wake . --plot

# 处理矩形几何的完整 wake（Wlong + Wquad + Wdipole）
echo2d postprocess wake . -g recta

# 批量处理所有步骤
echo2d postprocess all .
```

### Step 6: 可视化

```bash
# Wake 图
echo2d visualize wake runs/001_baseline/processed/wake/wake_monopole.txt

# 对比多个运行
echo2d visualize compare runs/001_baseline runs/002_fine

# 模态分解（矩形几何）
echo2d visualize modes runs/001_baseline/magn

# 几何结构图
echo2d visualize geometry my_geometry.txt

# 阻抗频谱
echo2d visualize impedance runs/001_baseline -m 0 --log

# 场监视器
echo2d visualize field runs/001_baseline -m 1 -n 1 --3d
```

### Step 7: 导出

```bash
# HDF5（包含所有数据）
echo2d export hdf5 runs/001_baseline -o my_results.h5

# CSV
echo2d export csv runs/001_baseline/processed/wake/wake_monopole.txt
```

## 后处理与可视化

### Wake 后处理详解

#### 圆形几何输出

| 文件 | 内容 |
|------|------|
| `wake_monopole.txt` | 纵向 wake (m=0): `s [mm]`, `W [V/pC]` |
| `wake_dipole.txt` | 横向 dipole wake (m=1): `s [mm]`, `W [V/pC/m²]` |
| `summary.txt` | Loss factor, peak, kick factor, RMS spread |

#### 矩形几何输出

| 文件 | 内容 |
|------|------|
| `wake_longitudinal.txt` | 纵向 wake: `s [mm]`, `W_long [V/pC]` |
| `wake_quadrupole.txt` | 四极 wake: `s [mm]`, `W_quad [V/pC/mm]` |
| `wake_dipole.txt` | 偶极 wake: `s [mm]`, `W_dipole [V/pC/mm]` |
| `summary.txt` | Loss factor + kick factors |

### 阻抗计算

```bash
# 计算 m=0 模态的阻抗
echo2d postprocess impedance runs/001 -m 0

# 输出表格显示 DC、峰值频率、对数采样频率处的 Re(Z)/Im(Z)/|Z|
# 可选 CSV 导出
echo2d postprocess impedance runs/001 -m 1 -o impedance.csv

# 可视化阻抗频谱（双面板：|Z(f)| + Re/Im）
echo2d visualize impedance runs/001 -m 0 --log
```

### HTML 报告

```bash
echo2d postprocess report runs/001_baseline
# 生成 postprocess_report.html，包含：
# - 运行元数据
# - Loss/kick factor 表格
# - 嵌入的 wake 图
# - 网格收敛信息
```

## 网格收敛研究

验证仿真结果对网格分辨率不敏感：

```bash
echo2d run converge -p myproject -m "2.0 1.0 0.5" -j 4
```

这会在三种网格分辨率下运行：
- 粗网格 (2.0×)：`StepY = 0.0004 m`, `StepZ = 0.0004 m`
- 标准网格 (1.0×)：`StepY = 0.0002 m`, `StepZ = 0.0002 m`
- 细网格 (0.5×)：`StepY = 0.0001 m`, `StepZ = 0.0001 m`

收敛判据：相邻两个分辨率的 loss factor 差异 < 5%。

## 场监视器

场监视器记录仿真域中特定位置的电磁场随时间演化。

```bash
# 列出可用的监视器
echo2d postprocess field runs/001_baseline --list

# 提取单点时间序列（生成 MATLAB 兼容的 PointMonitor.txt）
echo2d postprocess field runs/001_baseline \
    -m 1 -n 2 -c Ez \
    --extract-point "0.03,0.0015"

# 从多个模态合成总场（矩形几何）
echo2d postprocess field runs/001_baseline \
    --synthesize -c Ez --n-modes 15 \
    --x0 0.025 --x 0.025

# 3D 曲面图
echo2d visualize field runs/001_baseline -m 1 -n 1 --3d

# 时间序列动画
echo2d postprocess field runs/001_baseline -m 1 -n 1 \
    --animate field.gif --fps 10
```

### 场监视器参数

输入文件中配置：

```
FieldMonitor = Ez s 0 0.1 0 0.02 0 2 10
```

| 参数 | 含义 |
|------|------|
| `Ez` | 场分量（Ex/Ey/Ez/Hx/Hy/Hz） |
| `s` / `z` | 时间类型：s = 共动坐标系，z = 实验室坐标系 |
| `z0 z1` | 纵向范围 [m] |
| `y0 y1` | 横向范围 [m] |
| `s0 s1` | s 坐标范围 [m] |
| `N` | 采样间隔（时间步数） |

## 故障排除

### ECHO2D 找不到

```bash
echo2d system detect    # 自动检测
echo2d system check     # 检查所有依赖
```

如果自动检测失败，手动指定：
```bash
echo2d run start --exe /path/to/ECHO2D
```

### 仿真超时

```bash
echo2d run start --timeout 7200   # 2小时超时
```

### 矩形几何后处理失败

确保 `magn/` 和 `elec/` 两个子目录都存在（矩形几何需运行两次）：
```bash
ls runs/001_baseline/magn/wakeL_01.txt
ls runs/001_baseline/elec/wakeL_01.txt
```

### Python 依赖缺失

```bash
pip install -e ".[dev]"
echo2d system check     # 验证
```

### 获取帮助

```bash
echo2d --help                    # 顶层帮助
echo2d <command> --help          # 子命令帮助
echo2d <command> <sub> --help    # 具体命令帮助
```
